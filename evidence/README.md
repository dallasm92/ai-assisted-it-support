# Evidence Guidelines (Screenshots + Recordings)

I capture evidence when it improves credibility or repeatability.

## Best moments to screenshot
- before/after config screens (sanitized)
- command outputs showing the symptom and the fix
- key logs that prove the root cause
- network diagrams (simple is fine)

## Best moments to screen-record (30–90 seconds)
- reproducing the issue
- running the test plan (commands + results)
- validating the fix

## Redaction reminders
- remove emails/usernames if not required
- redact tokens/keys/serials
- keep only the lines that matter
